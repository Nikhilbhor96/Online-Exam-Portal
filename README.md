# Online-Exam-Portal
Setup (code)

Python check karo (3.10 ya upar chahiye):

python --version

Install karte waqt “Add Python to PATH” tick karna.

Project folder aur virtual environment:

mkdir online_exam_portal
cd online_exam_portal
python -m venv venv
venv\Scripts\activate

(Mac/Linux par: source venv/bin/activate)

Django install

pip install django
python manage.py runserver
